# Stitch Glossy Home Property Manager

A complete property and tenant management system built for tracking rooms, partitions, rent collections, and monthly utility expenses (ADDC, WiFi, Maintenance, etc.).

## Features
* **Room Inventory & Tenant Tracking**: Monitor occupied and vacant rooms/partitions across different buildings.
* **Dashboard & Financial Summary**: Automated calculation of total rent collections, utility costs, and net balance.
* **Expense Management**: Track ADDC, WiFi, gas cylinders, and maintenance charges easily.
